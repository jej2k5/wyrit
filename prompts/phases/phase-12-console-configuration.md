# Phase 12: Console, configuration

Add a local console: `python -m wyrit.console --config wyrit.toml [--port N]`, default port 4790. It binds 127.0.0.1 only, rejects other Host headers, and requires a random per-launch token on every change (embedded in the page, compared in constant time, never in JSON responses or logs). Serve every response with a strict CSP (`default-src 'none'`, nonce'd script and style, `font-src 'self'`, `connect-src 'self'`); load nothing external. Use only the standard library (`http.server` with threads) and plain HTML, CSS and JavaScript; add no dependency and no build step.

Pages, all driven by the same `load_config` validation and the phase 9 `reload`:
- **Servers:** add, edit, disable and remove downstream servers; test a connection before saving; show each server's health and discovered tools.
- **Capabilities:** searchable catalog with schema, read/write class and exposure toggle.
- **Policy and limits:** write allowances per server and capability; the phase 10 limits with effective value and source.
- **Secrets stay out:** headers reference environment variable names; show only whether each is set, never its value.
Writes go to `wyrit.toml` atomically with one backup, then `reload`. An invalid change is refused with the reason and leaves the file and the running host untouched. The file stays the source of truth: hand edits and console edits are interchangeable.

Design: the HONA product family system shared with MCPxy and ReplCRM. Warm graphite dark theme and stone paper light theme at parity (follow the system setting, plus a toggle), tokens in OKLCH: dark surfaces `oklch(0.13 0.006 70)`, `0.17`, `0.22`, `0.27`, `0.34` at the same chroma and hue; dark text `oklch(0.94 0.006 80)` down to `0.58`; light surfaces `oklch(0.985 0.004 75)`, `0.96`, `0.93`, `0.88`, `0.82`; light text `oklch(0.22 0.008 75)` up to `0.55`. Wyrit's single accent is teal, `oklch(0.72 0.11 200)` dark and `oklch(0.47 0.11 205)` light, used only for the primary action, focus, the active nav item and live state. Status colours with a glyph each: ok `oklch(0.72 0.13 145)`, warn `oklch(0.80 0.15 80)`, error `oklch(0.70 0.16 28)`, denied `oklch(0.68 0.15 310)`. JetBrains Mono (self-hosted from `src/wyrit/console/assets/`, already in the repository with its OFL licence; include it as package data) for all operational text, the system sans for prose. Sidebar with small uppercase section labels (`.6875rem`, `.06em`), a health strip of labelled readouts instead of metric tiles, flat panels with 1px hairlines, tables with uppercase headers. No gradients, glass, shadows at rest or cards inside cards. Plain words: say what is wrong and how to fix it. Must work at 390px wide without sideways scrolling.

Tests (offline, no browser): Host and token checks; CSP header; every page renders; adding a server through the API produces the same TOML a hand-written file would; a secret value never appears in any response, the file or logs; an invalid change leaves file and host untouched. Produce the phase handoff.
